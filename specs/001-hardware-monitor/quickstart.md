# Quickstart & Validation

目前只有设计和 Spec Kit 文件，以下运行入口是实现阶段必须交付的接口，现在尚不能执行。

## 普通用户安装验收

首选公开的一行安装命令 → 下载/校验预编译包 → 管理员授权后安装至系统Applications并注册LaunchDaemon → 完成可能的系统首次批准 → 选择语言/创建账户 → 自动打开本机概览。命令尚未实现/发布，流程见 [free-command-install.md](free-command-install.md)。新安装默认启用系统级开机自启动，可通过管理员授权关闭；手机连接独立设置且默认关闭；普通用户只执行安装命令，不执行下方开发命令。

在没有 Xcode、Node、Homebrew、Docker 和额外数据库的干净 M 系列 Mac 上验证。至少5名首次使用者，至少4名从安装器完成包下载到看到数据不超过3分钟（含可能的首次批准）；另记录命令开始到可用的总耗时；可选手机证书信任/配对另测。安装后断网仍能完成本机初始化及监测。

首版内嵌SQLite：30天系统历史和7天应用摘要自动保存，用户不安装数据库。常规升级保留账户、配对及已提交历史，重启需重新登录；详细设计见 [history-storage.md](history-storage.md) 和 [installation-and-storage.md](installation-and-storage.md)。

## 开发者前提与计划命令

使用 M 系列 Mac、macOS 14+、Swift 6/Xcode 工具链；React + TypeScript + Vite前端构建需要Node（仅开发时）。锁定依赖后：

```bash
cd cloud-mac-monitor
npm ci --prefix web
npm run build --prefix web
swift build -c release
swift test
./scripts/package-app.sh
```

打包后通过 `.app` 控制端启动服务，创建本机账户并打开页面；局域网操作依次为：开启 LAN → 自动选择可用接口/地址 → 手机信任专用证书并核验指纹 → 打开二维码配对 → 账户登录 → 查看数据。记录实际 Safari/iOS 与桌面浏览器版本及所用证书信任步骤，不采用忽略 TLS 验证的测试结果作为通过依据。

## 管理员授权探针（G4，先于完整界面）

T004先在隔离测试Mac实现最小ad-hoc控制端及固定维护工具：终端sudo引导安装，图形端NSAppleScript管理员授权；验收取消无变更、普通UID运行、enable/start/disable/stop状态表及卸载。最低支持与当前macOS分别记录；失败不跳过图形入口门槛。当前只设计，不在本文执行系统安装。

## 能力探针（先于完整开发）

预期命令：`swift run -c release CapabilityProbe --output artifacts/capabilities.json`。报告芯片/系统版本、传感器字段、权限失败、GPU 来源、进程可读比例及每适配器 CPU 时间；禁止收集完整命令行或用户文件内容。

至少验证基础 M1 8GB、一种 Pro/Max、不同代基础款；可用硬件不够时保留 unverified，绝不把编译 arm64 当真机验证。现有设计环境 x86_64 的输出不构成 M 系列实测。

## 性能场景

1. 关闭调试/采样分析工具，固定 Release 构建、屏幕亮度、供电、系统设置和进程负载；保存设备、系统、浏览器、依赖锁文件及版本信息。
2. 每场景预热5分钟，外部低开销 Benchmark 以1秒窗口记录30分钟，重复3次。测量程序本身单独记录开销；不使用被测网页作为唯一测量工具。
3. 所有场景默认启用历史记录。A：无查看者、LAN 开启但无连接；B：一台远程设备打开概览与排行；C：Mac 本机页面；D：3个活动页面；E：2,000进程压力场景；F：远程1客户端24小时。
4. CPU = 所有常驻组件累计 CPU 时间差 / 墙钟测量时长 ×100；100%代表单核满载。记录平均、1秒采样 p95、峰值。内存各组件 footprint 同时求和，记录 p95/峰值，并另报 RSS。
5. 浏览器采用干净配置的同一进程生命周期，空白页与监测页交替测量；覆盖相关 renderer、GPU、网络进程，报告增量及噪声。Mac 后台+浏览器单列合计，手机自身耗电另报。
6. 对照 spec SC-001/002/005；记录 wakeups/s，基于持续系统1秒/应用4秒重新建立诊断基线，不沿用旧无人查看降频结果；记录磁盘写入、流量和扫描耗时。不能在测试前关闭温度/排行后声称完整配置达标。
7. E 场景允许显式降频，但须报告实际间隔、覆盖比例和30秒内扫描是否完成；不把它混入500进程预算结果。
8. F 比较首个稳定小时与最后一小时 footprint、连接数/缓存数/文件句柄；内存差≤5 MiB且不超场景预算，验证日志轮转与历史固定容量。

实现提供 `scripts/benchmark.sh --scenario idle|remote|local|three-clients|many-processes|soak --duration 1800`；输出 `artifacts/benchmarks/<build>/<scenario>.json` 和人工可读报告。该脚本不得悄悄改变机器设置或自动创建2,000个进程；压力夹具须显式启动并保证回收。

## 正确性与恢复

- 受控单线程满载验证进程单核约100%、整机约100/N%；多线程可大于100%。与独立同口径源在相同窗口对照。
- 内存比较同一 footprint 字段；不强求等于 RSS 或活动监视器所有内存栏。记录共享进程聚合误差。
- 温度用同传感器参考读数对比，差≤3°C；传感器名与字段映射经负载变化验证，缺失/异常必须显示原因。
- 固定夹具测试 PID 复用、计数回绕、首样本、拒绝读取、短命进程、部分应用成员不可读、重复归组。
- 休眠10分钟后恢复：速率无巨峰，历史留空，10秒内基础数据恢复；手机隐藏后断流，Mac仍持续1秒/4秒采集；返回后重新订阅并读已有新鲜快照。
- 断网、切换接口、证书轮换、慢 SSE、重连与第4客户端；缓存和发送队列均保持上限。
- 未配对请求、过期票据、重复兑换、伪造 Origin/Host、跨会话 viewer 操作被拒；撤销设备5秒内断流。
- 验证系统启动且数据卷可用后，在尚未登录桌面时已1秒/4秒采集，不弹浏览器；退出Mac登录仍记录，手机完成配对和Web登录后可读。FileVault解锁阶段单列；验证UserName有效UID非root、无GUI采集与专用TLS文件，关闭/授权取消/系统禁用、升级保留关闭选择、锁屏/注销及崩溃节流。
- 卸载/停止释放监听端口并注销system任务，下次开机不出现残留自启动服务；未知机型基础指标仍工作。

## 历史、认证与React专项验收

- 准备30天系统桶与7天应用桶的固定夹具，验证1m/5m/1h均值按覆盖加权、分辨率切换无重复点、每应用桶最终并集≤30；未知/未入榜显示未保留，不显示0。
- 正常关闭验证刷出partial桶；强制终止验证已提交记录可恢复与lastCommittedAt准确，未完成应用桶可能丢5分钟。模拟系统睡眠、时钟回拨、重复事务和采样缺失，不能覆盖旧segment或制造速率尖峰。
- 测量60秒批量事务、每小时清理、checkpoint的实际I/O；统计主库/WAL/SHM总大小及24小时物理写入，不能仅凭SQLite行数判断SC-013通过。
- 磁盘满/只读、损坏历史库、超长查询与写队列满时，历史显示错误，实时服务继续；恢复账号库需本机操作，不能远程重新注册。
- 验证本机setup票据、并发创建只有一个成功、配对仅授予设备资格、正确密码登录、错误重试限额、注销/改密/设备撤销关闭SSE。账号重启保留、账户会话失效、历史保留。
- 单独跑Argon2id登录/错误密码压力场景，报告认证瞬态和1分钟后的稳定footprint。不得将一次64MiB密码计算藏在“40MiB常驻”的说法里，或为了预算改成快速通用散列。
- 三种语言覆盖原生安装引导与React创建/登录/历史/设置页面；切换语言不丢表单输入、不重复创建SSE。用fake计数端点或真实连接日志验证每页面仅一个活动流。
- 多语言文件与贡献流程见 [localization.md](localization.md)：仅添加第四种测试语言目录，验证自动生成 Web/原生资源及选择器，不修改业务代码；正式语言缺失键、重复属性、参数错误应阻止构建。验证字典加载失败回退、快速切换竞态，以及未选语言无字典请求。`npm --prefix web run i18n:check` / `npm --prefix web run i18n:generate` 为计划开发命令，当前尚未实现。
- 使用Vite生产构建测首屏gzip≤200KiB、全部脚本样式≤400KiB目标；记录React页面的实际CPU、浏览器进程内存与长历史图表渲染时间。隐藏页无持续重绘或历史轮询。
- 从无Apple发行证书的环境完成源码构建、ad-hoc打包及首选免费安装/更新，按 [free-command-install.md](free-command-install.md)验证包校验、系统目录及管理员授权取消、Gatekeeper批准及策略拒绝；可选公证渠道另测，不阻塞首版。
- 按 [realtime-data-flow.md](realtime-data-flow.md)验证0/1/3客户端采集轮数不变、最近五分钟内存查询、跨库分界去重、崩溃后聚合精度回退及4MiB近期缓存上限。新增登录页状态、刷新CSRF恢复、401导航、离线不误登出、SSE单连接与客户端stale计时验收。

## 发布判定

新增安装验收：免费安装器下载/校验失败、首次批准及企业策略拒绝、系统目录与受限安装目录、端口占用自动选址、重复启动单实例、后台权限拒绝、升级过程中服务正在运行、数据迁移失败恢复、停止与取消开机启动、保留/删除数据清理。三种语言均覆盖用户提示。损坏状态文件不得触发无账户自动重置；直接删除应用的清理限制须在帮助中可见。

所有 P1 用户故事完成、预算实测通过、支持矩阵明确时才能称首版完成。温度尚不可用或预算未经验证时只能交付注明限制的预览版。测试报告须列出未验证机型，不要求用户把“所有 M 系列”理解成未来硬件也已有保证。

## 本轮审查的定向验收

- 30天720个小时桶在maxPoints=600时按需合并，校验加权值/极值/覆盖；测试maxPoints=1、非对齐范围、多segment/回拨/缺口不能跨段合并及预算不足返回；容量使用实际字节，不把267,264/60,480名义行数当硬上限。
- 0/1/3客户端用不同应用排序/过滤，通知≤2KiB、页≤128KiB，不增加扫描；旧cursor及迟到响应、翻页新版本、429和慢连接行为有界。
- 缺Origin的GET/SSE正常认证读取；错误Host/跨源Origin/null、缺Origin写操作及缺CSRF被拒。
- 暂停后近期五分钟仍可读，重启仍暂停；恢复不补写暂停期。clear与提交/查询/扫描交错及事务失败/崩溃，验证epoch隔离、旧曲线清理、当前实时值与账号不误删。
- disable保持本次运行但重启不启动，stop禁用且退出，disabled时start拒绝，enable恢复；升级关闭但在运场景按文档保持关闭且停止，授权取消/局部失败反馈真实。
