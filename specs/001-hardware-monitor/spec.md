# Feature Specification: Mac 硬件与应用资源监测

**Feature Directory**: `specs/001-hardware-monitor`（不创建 Git 分支）
**Created**: 2026-09-30
**Status**: Design updated for persistent history, account authentication, localization, React frontend and open-source distribution; implementation pending
**Input**: macOS 硬件占用、温度、应用资源排行；Web 界面；CPU 与内存占用极低。

## User Scenarios & Testing

### User Story 1 - 看到系统状态与温度 (Priority: P1)

用户打开网页，看到整机 CPU、内存、GPU 可用指标、磁盘读写、网络吞吐与温度，判断当前瓶颈。

**Why this priority**: 核心需求是快速了解机器状态。
**Independent Test**: 对已验证的 M 系列设备施加 CPU 负载，查看趋势、温度和数据新鲜度。
**Acceptance Scenarios**:

1. **Given** 服务已运行，**When** 打开概览，**Then** 3 秒内展示 CPU/内存快照，速率类指标完成两次采样前显示“采样中”。
2. **Given** 有已验证温度传感器，**When** 查看温度，**Then** 显示摄氏度、传感器名称、最高值及更新时间。
3. **Given** 指标不可用或读取失败，**When** 查看页面，**Then** 显示具体状态，不以 0 代替；其他指标继续刷新。

### User Story 2 - 找到占资源的应用 (Priority: P1)

用户按 CPU、内存或磁盘读写排序，展开应用查看其进程；无法可靠归属的进程单独显示。

**Why this priority**: 定位占用来源，让监测数据可用于排查。
**Independent Test**: 运行已知多进程测试应用，确认归组、排序和退出后的处理。
**Acceptance Scenarios**:

1. **Given** 一个应用含多个进程，**When** 查看排行，**Then** 每个进程至多归入一个应用，并可查看成员及归属依据。
2. **Given** 一个线程持续满载，**When** 查看 CPU，**Then** 单核口径约为 100%，整机口径约为 100/N%，N 为逻辑核数。
3. **Given** 系统进程受权限限制，**When** 扫描进程，**Then** 显示覆盖数量及“部分可见”，不暗示排行覆盖全部系统资源。
4. **Given** 持续运行的高负载进程，**When** 打开排行，**Then** 10 秒内可定位；应用占用和硬件温度不构成温升因果归因。

### User Story 3 - 用手机或另一台电脑查看 (Priority: P1)

用户在 Mac 上开启局域网访问，给自己的设备配对，然后使用浏览器查看同一份数据。

**Why this priority**: 用户明确要求，并可省去 Mac 本机浏览器开销。
**Independent Test**: 手机在同一 Wi-Fi 上配对，另一未配对设备访问被拒绝；撤销后原手机失效。
**Acceptance Scenarios**:

1. **Given** 局域网访问未开启，**When** 远程连接，**Then** 服务不可从网络访问。
2. **Given** 用户开启访问，**When** 按提示核验并信任本机证书、完成一次性配对并登录账户，**Then** 手机能访问加密监测页面。
3. **Given** 已配对设备，**When** 用户在 Mac 撤销它，**Then** 5 秒内关闭其流并拒绝后续数据请求。
4. **Given** 3 个客户端，**When** 同时查看，**Then** 共享采集，慢客户端不阻塞其他客户端；第 4 个活动流收到明确限额提示。

### User Story 4 - 长期开启且低占用 (Priority: P1)

用户在工作期间保留服务，持续记录近期变化；关闭页面后停止传输和页面渲染，采集继续。

**Why this priority**: 极低 CPU 和内存占用是产品约束。
**Independent Test**: 分别运行无客户端、一个远程客户端、本机网页及 3 客户端场景，按下述预算验收。
**Acceptance Scenarios**:

1. **Given** 最后一个页面关闭或隐藏，**When** 连接释放，**Then** 停止推送但继续系统10秒、应用10秒共享采集；只有电源/热状态、睡眠或显式故障降级改变采样。
2. **Given** Mac 睡眠后唤醒，**When** 服务恢复，**Then** 历史显示空档，速率重新建立基线，10 秒内恢复基础快照。
3. **Given** 连续运行 24 小时，**When** 查看服务开销，**Then** 缓存无持续增长，近期内存趋势与已保存历史可用，重启后恢复已提交历史，未保存区间明确标为缺口。

### User Story 5 - 创建账户并登录 (Priority: P1)

首次启动时，用户在 Mac 本机创建唯一的用户名与密码，此后通过登录页面访问监测数据；不依赖云账号。

**Why this priority**: 用户明确要求单账户登录。
**Independent Test**: 在无账户状态下完成创建，重启后登录，验证未登录无法读取数据及无法创建第二个账户。
**Acceptance Scenarios**:

1. **Given** 尚无账户，**When** 用户从 Mac 本机打开页面，**Then** 显示创建账户页面；远程请求不能抢先创建账户。
2. **Given** 已有账户，**When** 用户打开未登录页面，**Then** 显示登录页面；正确凭据建立会话，错误凭据不返回数据。
3. **Given** 已创建账户，**When** 重启或再次请求创建账户，**Then** 账户保留且禁止创建第二个账户；并发首次创建也只能成功一次。
4. **Given** 用户注销或修改密码，**When** 再次使用相应旧会话，**Then** 无法读取数据；修改密码使全部旧会话失效。
5. **Given** 用户忘记密码，**When** 从受当前 Mac 用户身份保护的本机控制端恢复账户，**Then** 可以重设密码并撤销旧会话，远程入口不能触发恢复。
6. **Given** 局域网访问已开启，**When** 未配对设备尝试登录，**Then** 先要求完成配对；配对仅授予设备访问资格，不替代账户登录。

### User Story 6 - 使用自己的语言 (Priority: P1)

用户可在创建账户和登录之前选择语言，并在使用过程中切换。

**Why this priority**: 多语言是用户明确要求。
**Independent Test**: 逐一使用简体中文、繁体中文和英语完成创建、登录、配对及查看流程。
**Acceptance Scenarios**:

1. **Given** 首次打开页面，**When** 浏览器语言匹配支持语言，**Then** 自动选择该语言；不匹配时回退英语。
2. **Given** 任意页面，**When** 用户切换语言，**Then** 导航、表单、指标标签、错误提示与状态文本同步更新，监测订阅不重复创建。
3. **Given** 用户已选择语言，**When** 刷新页面或重新打开同一浏览器，**Then** 保留选择；日期和数字按所选语言格式化，应用名称及传感器标识保留原值。
4. **Given** 贡献者新增一种语言，**When** 添加该语言的元信息与翻译文件并通过校验，**Then** 重新构建后自动出现在语言选择器中，无需修改业务代码；缺失键、参数不匹配及无效资源有明确诊断。

### User Story 7 - 安装后直接使用 (Priority: P1)

用户复制执行一条公开安装命令，自动下载、校验并安装预编译应用；完成可能的系统首次批准与账户创建后查看网页，无需安装运行环境或配置数据库。

**Why this priority**: 用户明确要求傻瓜式安装，初始配置不能依赖开发知识。
**Independent Test**: 在从未安装开发工具的受支持 Mac 上，由首次使用者安装、创建账户、查看数据，然后升级并卸载。
**Acceptance Scenarios**:

1. **Given** 全新受支持的 Mac，**When** 用户执行免费一行安装命令，**Then** 安装器校验包，在管理员授权后安装到系统目录并注册LaunchDaemon，无需开发依赖或Apple付费会员；若系统阻止启动，提供针对该应用的明确批准步骤，不关闭系统安全检查。
2. **Given** 首次启动，**When** 完成语言选择与账户创建，**Then** 自动启动所需组件并打开本机概览，地址、可用端口及数据目录均自动处理。
3. **Given** 用户关闭自动启动或暂不启用局域网，**When** 完成首次设置，**Then** 本机监测可正常使用；后续能从应用内开启这些选项。
4. **Given** 用户开启局域网访问，**When** 跟随设备引导完成证书信任、配对及账户登录，**Then** 手机可查看；系统要求的操作有清晰说明，失败不影响本机使用。
5. **Given** 有新版本或已有版本重新安装，**When** 用户执行指定版本安装命令进行更新或重装，**Then** 保留账户、设置和配对数据，不重复创建后台服务；升级失败提供可执行的恢复入口。
6. **Given** 用户准备卸载，**When** 选择停止并清理，**Then** 退出服务、取消开机启动，并可选择保留设置或删除本机应用数据；删除前明确提示范围。
7. **Given** 完成首次安装且自动启动已获系统允许，**When** 重启Mac且系统启动/数据卷可用，但尚未登录桌面，**Then** 无需登录Mac桌面、手动打开应用或登录网页即可持续采集，Mac用户注销后也继续；不自动弹出浏览器，账户与已提交历史保留，网页重新登录后可查看。
8. **Given** 用户关闭自动启动或在系统设置中撤销许可，**When** 下次开机或升级应用，**Then** 不重新启用服务自启动；权限受阻时显示真实状态和恢复入口。

### User Story 8 - 回看系统与应用历史 (Priority: P1)

用户选择过去的时间范围，回看CPU、内存、温度与应用排行摘要，重启后仍可查询。

**Why this priority**: 用户明确要求保存历史，同时要保持极低系统负载。
**Independent Test**: 记录已知负载，正常重启和模拟异常终止，查询24小时/7天/30天范围并核对覆盖和保留策略。
**Acceptance Scenarios**:

1. **Given** 正常记录中，**When** 关闭所有网页，**Then** 仍按系统10秒/应用10秒持续采集，并按原分钟事务/5分钟摘要规则保存，界面显示对应采样和存储精度。
2. **Given** 已保存多天数据，**When** 查询整机历史，**Then** 最近24小时使用1分钟桶，1～7天使用5分钟桶，7～30天使用1小时桶，并返回每桶覆盖与极值。
3. **Given** 查询应用历史，**When** 选择7天内时间段，**Then** 显示每5分钟的CPU、内存、磁盘I/O各Top10的并集（最多30组），标明这是抽样排行摘要，不是全部应用的完整活动日志。
4. **Given** 正常停止服务，**When** 重新启动，**Then** 已提交历史与停止前成功刷新的部分桶仍在；睡眠、退出、采样失败形成缺口，不补零。
5. **Given** 非正常终止且写入无积压，**When** 重启恢复，**Then** 已成功提交的历史可恢复；未提交系统样本通常最多约60秒、尚未完成的应用桶最多约5分钟可能丢失，显示实际最后保存时间。
6. **Given** 达到保留期、容量阈值或磁盘写入失败，**When** 服务处理历史，**Then** 先回收过期数据；不足时显式缩短历史或暂停记录，实时监测继续且不形成无界队列。

### Edge Cases

- PID 复用、采样中退出、权限变化、未知辅助进程、应用名相同。
- 睡眠、时钟校准、计数器回绕、网络接口切换及 VPN 多层统计。
- 无风扇机型、多 GPU、统一内存、未知传感器、错误单位及失效读数。
- 未知或新 M 系列仍提供基础能力；显示未验证传感器，不误标为已支持。
- 手机切后台、网络断开、证书变化、Mac IP 改变、慢连接和配对暴力尝试。
- 进程数从 500 增至 2,000；主动降频时明确显示有效间隔和扫描覆盖。
- 并发首次创建、错误密码重试、账户文件写入失败、忘记密码、会话失效及注销时仍存在活动流。
- 不支持的浏览器语言、缺失翻译、长文本、语言切换时表单输入保留。
- 从只读安装映像直接运行、目标目录无写权限、端口已占用、重复启动、旧版本覆盖、磁盘空间不足、配置损坏和升级中断。
- macOS 拒绝后台运行或局域网访问；用户取消可选步骤；手机证书未信任；应用被直接拖入废纸篓而未执行清理。

## Requirements

### Functional Requirements

- **FR-001**: 显示整机及可选每核 CPU、物理内存及分类、内存压力状态（可用时）、交换区。
- **FR-002**: 显示可验证的硬件温度、热状态、GPU 总体指标；对未验证机型明确标注能力边界。
- **FR-003**: 提供应用/进程 CPU、内存及可用磁盘读写排行、排序、搜索和展开；默认 Top 20。
- **FR-004**: 指标携带单位、来源、时间、统计口径及有效性；缺失值不当成真实零值。
- **FR-005**: 显示系统磁盘读写速率及各网络接口吞吐；不把吞吐标为硬件占用百分比，不重复汇总 VPN 与底层链路。
- **FR-006**: 唯一调度器持续共享采集，默认系统10秒、应用10秒，不随客户端数重复采集；可见性仅控制推送，电源/热状态及故障可显式降频，睡眠暂停且不伪造实时数据。
- **FR-007**: 最近五分钟优先读有界共享内存，较早历史读数据库；持久保存30天系统历史、7天应用排行摘要，分级精度和分钟批量提交，不随查看者存在与否改变默认记录频率。内存高精度与持久聚合可重叠，重启降至已保存精度。
- **FR-008**: 提供本机访问和用户开启的局域网加密访问，配对、设备撤销及最大 3 个活动流；管理操作限 Mac 本机。
- **FR-009**: 使用LaunchDaemon在macOS启动且数据卷可用后自动启动后台采集及Web服务，与Mac用户登录/注销无关，新安装经管理员授权默认启用；不自动打开浏览器，不依赖网页登录。用户可关闭自动启动（保持本次运行）、启动已启用服务或显式启用并启动、停止并关闭开机启动、打开页面、开启/关闭LAN并查看自身开销；升级保留选择，卸载移除后台注册。
- **FR-010**: 故障、权限或能力不足时各采集项独立降级，不影响核心 CPU/内存查看。
- **FR-011**: 手机网页适配 360px 宽度，隐藏页面停止刷新，断开重连时清楚显示状态。
- **FR-012**: 支持 M 系列基础监测，发布兼容矩阵；逐应用 GPU、逐应用网络、功耗及风扇控制不作为首版保证能力。
- **FR-013**: 首次启动仅允许 Mac 本机创建一个用户名/密码账户，账户跨重启保存；不提供公开注册或第二个账户。
- **FR-014**: 本机和局域网网页都提供登录与注销；所有监测请求和活动流要求账户会话，局域网另须设备配对。限制登录重试，错误凭据返回统一提示；密码不以明文保存或记录。
- **FR-015**: 用户可在本机修改或恢复密码；密码变更撤销全部旧会话，注销立即停止对应监测流。已有的设备撤销功能继续生效。
- **FR-016**: 首版完整支持简体中文、繁体中文、英语；自动匹配浏览器语言，允许手动选择并按浏览器保存偏好。创建、登录、配对、设置、指标、错误和状态均须本地化，缺失翻译回退英语。翻译使用按语言及功能划分的独立 JSON 文件，稳定键与业务代码分离；新增语言仅添加元信息和翻译文件，经校验、重新构建后自动注册。普通插值参数为格式化后的字符串，复数计数为受限整数；Web 与原生资源从统一翻译源生成，按需加载，不运行额外翻译服务；详见 [localization.md](localization.md)。
- **FR-017**: 提供面向 M 系列 Mac 的免费一行安装入口，下载已编译应用；首次使用不要求安装 Docker、数据库、开发工具或浏览器插件，允许一次终端命令及可能的应用特定系统批准。系统级安装/维护需要管理员授权；所有运行必需资源随应用提供，安装后本机监测可离线使用。
- **FR-018**: 首次引导提供语言、账户创建、默认开启且可通过管理员授权关闭的“开机自动启动服务”设置，以及默认关闭的局域网选项；后台注册需显示已启用/待系统批准/关闭/错误的真实状态；自动选择可用本机端口、创建应用数据目录并打开本机界面。尚未创建账户时禁止启用远程监测。
- **FR-019**: 应用提供按需检查更新、复制指定版本安装命令、停止监测和清理入口；首版通过同一安装器更新，常规升级保留持久数据，失败不静默覆盖有效数据；关闭设置窗口不等同于停止后台监测，界面需说明。
- **FR-020**: 账户、设置、设备资格与本机密钥在系统数据目录中跨重启保存，独立于用户登录钥匙串，由应用管理其创建、版本迁移和错误恢复；用户无需接触数据库文件。配置/账户损坏时不得自动退回无账户状态或允许远程抢先创建。历史损坏不得自动删除账户。

- **FR-021**: 整机持久历史支持1分钟/5分钟/1小时分级查询，记录平均、最小、最大、样本数和覆盖时长；应用摘要为每5分钟最终排行并集，逐进程明细不长期保存。
- **FR-022**: 历史记录默认启用，用户可本机暂停或清空历史，暂停只停止持久保存，近期内存仍更新；恢复不回填暂停期；清空同时移除已保存历史、近期曲线与待提交数据，通过代次屏障阻止旧数据重现，不删除账户或当前实时值、不改变暂停选择；提供最近保存时间、当前磁盘用量、有效保留期和错误状态。自动清理、压缩精度及容量限制不能静默隐藏数据损失。
- **FR-023**: 历史查询有返回点数、范围及耗时限制，不随30天数据量增长阻塞实时采集；系统睡眠和时钟跳变不产生伪造速率。
- **FR-024**: 提供可公开发布的完整源码、依赖锁定信息、自构建说明和第三方声明；首选免费预编译包、ad-hoc代码签名及开源安装器，公开校验清单；Apple发行签名和公证为可选渠道，不作为首版硬门槛。开发者无需付费证书即可本地构建。发布许可证明确后再正式开源发布。

### Key Entities

设备能力、带状态的指标、系统快照、进程身份、应用分组、趋势桶、唯一账户、账户会话、语言偏好、查看会话、配对设备、历史策略、持久系统桶、应用摘要桶及采样配置。

## Success Criteria

### Measurable Outcomes

以下均为待实测的验收目标。CPU 按“一个逻辑核满载 = 100%”计，不除以核心数；内存为物理 footprint，另报告 RSS。所有服务、helper 和常驻控制端合并计入后台预算。

| 场景 | 后台平均 CPU | 后台 footprint p95 | 后台 CPU 每秒样本 p95 |
| --- | ---: | ---: | ---: |
| 无查看者，LAN 可开启但无连接 | ≤ 0.2% | ≤ 40 MiB | ≤ 1% |
| 1 个可见远程页面，默认频率 | ≤ 0.8% | ≤ 60 MiB | ≤ 3% |
| 3 个可见客户端，默认频率 | ≤ 1.2% | ≤ 75 MiB | ≤ 5% |

- **SC-001**: 上表在 Release 版、≤500 个可见进程、最多 16 个启用传感器、默认历史记录启用（最多64条系统序列、每桶最多30组应用摘要），持续系统10秒/应用10秒配置下，预热 5 分钟后测 30 分钟，三次均通过。M1 8GB 为最低性能参考机；不同芯片/系统组合单列结果。
- **SC-002**: Mac 本机打开一个网页的增量目标：浏览器相关进程合计平均 CPU ≤1%、footprint ≤120 MiB；后台与网页合计 ≤1.8%、≤180 MiB。采用同一浏览器空白页对照，不能只测 JS 堆；远程设备开销另报告。
- **SC-003**: 概览首次展示 ≤3 秒；默认 CPU/内存数据年龄 p95 ≤3 秒，应用实时首页排行 ≤10 秒（翻页暂停自动刷新时明确提示），温度 ≤12 秒；系统过载/降频时展示原因与实际间隔。
- **SC-004**: 配对并登录后手机能查看，与本机一致；未配对、未登录、已撤销及过期会话无法读取监测数据。
- **SC-005**: 24 小时运行最后一小时与首个稳定小时的平均 footprint 差值 ≤5 MiB，且始终在场景内存预算内；默认历史写入、聚合与清理必须计入开销；普通日志 ≤1 MiB/小时并轮转。
- **SC-006**: 固定窗口 CPU 对照误差 ≤5 个百分点，内存使用同字段对照误差 ≤5%；温度与同传感器参考工具差值 ≤3°C。输入及窗口不一致须标注，不能强求等于活动监视器所有显示值。
- **SC-007**: 已验证芯片/系统组合全部通过基础能力、温度与错误降级用例；无温度可读的组合标为“基础监测支持、温度未支持”，不得宣称已满足完整温度需求。
- **SC-008**: 首次创建、登录、错误凭据、并发创建、注销、密码恢复与会话撤销场景全部通过；重启后账户保留，任何入口均不能创建第二个账户或绕过登录读取指标。
- **SC-009**: 三种首版语言全部完成创建、登录、配对、概览、排行、历史及设置验收，并覆盖原生引导；这些页面无缺失翻译键或文本截断导致的不可用操作，刷新后保留手动语言选择。仅添加第四种测试语言的资源目录即可完成自动注册；校验拦截正式语言缺失键/参数错误，运行时加载失败可回退，切换保留表单且不增加 SSE 连接，未选语言不预加载字典。
- **SC-010**: 至少 5 名首次使用者在受支持的干净 Mac 环境中，至少 4 名能在安装器完成包下载后 3 分钟内独立完成校验安装、可能的系统首次批准、账户创建并看到 CPU/内存数据；允许一次安装命令，不安装开发依赖或手改配置。另记录命令执行到可用的总耗时；计时不含可选手机配对。
- **SC-011**: 系统目录安装、管理员授权及取消、包校验失败、下载中断、Gatekeeper批准/策略拒绝、端口冲突、重复启动、保留数据升级、升级失败恢复、取消开机启动和清理场景全部通过；更新允许一次安装命令，停止清理提供图形入口；免费ad-hoc管理员授权与系统服务状态转换须提前通过G4原型，授权取消无变更、局部失败显示实际状态。后台权限被拒时给出明确操作入口；验证数据卷可用后且未登录桌面时自动采集、退出Mac登录仍记录、不弹浏览器、网页未登录仍记录、关闭开关后升级不重启用、异常退出恢复与主动停止不被拉起。

- **SC-012**: 默认保留策略下，已提交历史跨重启可查询；模拟30天数据验证分级聚合、缺口、过期回收和重复写入幂等。最多8条系统序列、每条全部segment/连续段合计600点；查询时可合并为2h等更粗桶，保留加权均值、极值和覆盖，不跨segment/缺口；点数预算不足须明确拒绝而非截断历史。覆盖单/多segment及重启回拨夹具，30天查询响应p95≤500ms（本地服务端、参考M1、无外部系统过载）。
- **SC-013**: 默认参考负载下历史逻辑存储（数据库及相关活动文件）目标≤256MiB，历史物理写入目标≤128MiB/24h；写放大、清理和检查点必须计入，账号/更新下载/日志单列。容量保护触发时给出明确状态，超时查询及磁盘满不阻塞实时服务。以上为待实测目标，不代表SQLite天然能保证这些数值。
- **SC-014**: 静态网页、原生服务、嵌入式数据引擎均随应用分发；干净机器无需单独安装React、Node或SQLite。公开构建说明不含签名私钥/账户秘密，未配置Apple发行凭据也可构建并验证首选免费安装包与安装器。

- **SC-015**: 默认登录使用64MiB Argon2id工作内存且全局串行，登录是短时交互负载，单独报告CPU峰值/耗时/footprint；参考机正常登录目标≤1秒，完成60秒后回到原场景稳定内存预算。SC-001的稳态采样测试不含反复登录，不能据此宣称认证期间也满足≤40MiB；认证压力测试必须保证已有监测会话仍响应。

## Assumptions

- LaunchDaemon系统域运行、指定普通UID执行采集/Web，安装与系统启停/升级/卸载需管理员授权；FileVault未解锁、睡眠及关机期间不承诺持续采集。
- 免费一行安装为首选：预编译arm64应用及公开安装器，ad-hoc签名无需Apple付费会员。可能需要针对应用的系统首次批准；可选公证DMG以后提供。详见 [free-command-install.md](free-command-install.md)。
- 历史默认启用；SQLite作为应用内嵌实现，不增加用户安装步骤。系统精度和应用摘要规则为低负载默认值，可根据实际验证进一步调整并记录。
- 首版语言默认范围为简体中文、繁体中文和英语，可按用户要求调整。
- 用户确认整机30天、应用摘要7天。极短进程可能未被采到，历史内存峰值仅为已采样峰值；不承诺完整进程审计。
- 目标 macOS 14+，所有 M 系列；Intel 非本轮交付。当前执行环境显示 x86_64，不能用作 Apple Silicon 硬件支持证明。
- 第一版面向个人使用、同一 LAN，离线可运行；外网和多 Mac 集中管理留给后续需求。
- 默认持续采样系统10秒、应用10秒、温度10秒、GPU10秒；观看时按数据周期共享推送，无查看者停止传输。新频率与缓存成本仍须真机验证，见 [realtime-data-flow.md](realtime-data-flow.md)。
- 本机/局域网入口都需会话。局域网首次使用有证书信任步骤；无需云账号。
- 技术探针若证实无法达到性能或温度要求，应明确更新设计及支持范围，不把需求默默删掉。

## Explicit Technical Constraints

用户指定前端 React + TypeScript + Vite，构建产物为静态网页；后端仍为macOS原生低开销服务。技术细节与存储参数见 plan 和 history-storage。开源许可证暂推荐MIT，尚未代表用户授予实际代码许可。

## 本轮审查补充验收

- FR-003/FR-006/SC-003：三个页面按不同条件看应用排行，SSE通知只含共享扫描版本；GET排序/分页不增加硬件扫描。最新扫描后的旧cursor返回snapshotChanged，重试和内存有界。
- FR-022/SC-012：clear与待写事务、查询、采样同时发生时，成功后不再返回旧epoch；paused跨重启保留，recent仅内存可读不表示已保存。
- FR-014/SC-008：普通同源GET/SSE没有Origin也可登录读取；错误Host、跨源/null Origin、缺Origin写操作及缺CSRF按接口矩阵拒绝。
- FR-016/SC-009：英语参数名生成固定类型；普通插值误传数字、复数计数越界及原生位置转义均有校验，新增语言仍只维护JSON。

## 2026-10-03 usability revision

用户要求温度参考所附界面逐项显示：提供 CPU／图形／硬盘最高可读温度摘要与命名传感器列表，数值明确使用 °C；未知 SMC ID 不猜测硬件归属，详情保留原始 ID。增加内置／外接硬盘识别及只读 ATA／NVMe SMART 温度查询；设备或转接盒未提供读数时列出设备与不可用原因，不伪造数值。首次无账户时本机网页直接显示并提交创建账户，不要求先去控制台签发票据；已有账户／损坏状态不可重新注册，LAN 开户继续禁止。控制窗口明确刷新状态和局域网接口的用途。

## 2026-10-03 stop and sampling revision

用户明确要求 ⌘Q 退出停止 Agent：关闭窗口仍保留后台运行，但显式退出通过服务所有者 IPC 请求 shutdown，确认实际 PID 退出，失败保留控制窗口并显示错误；正常退出状态为 0，KeepAlive/SuccessfulExit=false 不重新拉起。保留开机启动偏好；用户注销／系统退出不误触发手动停止。默认系统、进程、温度、GPU 全部每 10 秒采集一次，低电量／严重热限制为 20 秒；SMART 保持 60 秒缓存。SMC 每批复用一个连接并缓存可读 key。温度命名参考用户指定 MacMonitor 的 M2 SENSORS.md；CPU／GPU 芯片、SoC、邻近、内存及 VRM 明确区分，不宣称已验证此项目的全部机型。
