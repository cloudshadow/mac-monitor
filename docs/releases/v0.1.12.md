# Mac Monitor v0.1.12

This release improves mobile sign-in and detail page layouts, preventing page-wide horizontal scrolling on narrow screens and with long device names.

## Changes

- Remove the fixed minimum page width so the layout fits narrow mobile screens.
- Keep sign-in form columns and controls within their available width.
- Wrap long device names and detail headings instead of letting them extend beyond the page.
- Add mobile Safari layout checks for narrow screens, landscape sign-in, all three languages, and expanded process and sensor details.

## Installation

Use the [installation commands in the README](https://github.com/cloudshadow/mac-monitor/blob/v0.1.12/README.md#install), or download the package for your architecture, `install.sh`, and the checksum files below.

Packages are provided for Apple Silicon (`arm64`) and Intel (`x86_64`) on macOS 14 or later. Apple Silicon is the target platform; the Intel package is available for development testing. Updates preserve your account, history, certificates, and service-start preferences.

The app uses ad-hoc signing and may require macOS first-launch approval. Installation requires administrator authorization. Sensor availability depends on the Mac model and drive connection.

## Validation

- Production web build and TypeScript checks.
- Seven Chrome browser tests and two mobile WebKit tests, including 280–390px layouts, landscape sign-in, long names, expanded details, desktop card alignment, and real LAN HTTPS page loading.
- Swift tests and localization checks.
- Package signatures, versions, and SHA-256 checksums for both architectures.
