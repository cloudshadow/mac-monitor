# Mac Monitor v0.1.11

This release aligns the disk and network throughput card with the two application Top 5 cards beside it.

## Changes

- Share grid rows across both desktop dashboard columns, keeping the throughput card's top and bottom edges aligned with the CPU and memory rankings.
- Adjust row heights for shorter desktop screens while keeping all five ranking entries visible.
- Preserve the stacked mobile layout.

## Installation

Use the [installation commands in the README](https://github.com/cloudshadow/mac-monitor/blob/v0.1.11/README.md#install), or download the package for your architecture, `install.sh`, and the checksum files below.

Packages are provided for Apple Silicon (`arm64`) and Intel (`x86_64`) on macOS 14 or later. Apple Silicon is the target platform; the Intel package is available for development testing. Updates preserve your account, history, certificates, and service-start preferences.

The app uses ad-hoc signing and may require macOS first-launch approval. Installation requires administrator authorization. Sensor availability depends on the Mac model and drive connection.

## Validation

- Production web build and TypeScript checks.
- Seven browser tests, including desktop alignment at 1280×720, 1366×768, 1672×941, and 1920×1080, mobile layout, and real LAN HTTPS page loading.
- Swift tests and localization checks.
- Package signatures, versions, and SHA-256 checksums for both architectures.
