# Mac Monitor v0.1.8

本次更新将产品名称统一为 **Mac Monitor**，更新透明 Logo，并重做深色全屏监控概览。

- 桌面概览按可视高度布局，温度、趋势、应用 Top 5 和吞吐在一屏展示；手机端支持纵向布局。
- CPU、内存、交换空间、GPU 和监控自身开销位于顶部；内存百分比按 `(App 估算 + Wired) / 总内存` 计算，不包含压缩内存。
- 新增内存分布、CPU / 内存 / GPU 趋势及磁盘与网络汇总图；移除 EN0–EN8 接口明细。
- 隐藏不可读的内置硬盘温度，折叠辅助温度及 PMU 测点，补充 PMU 说明。
- 修复刷新时翻译资源加载竞态，以及启动时传感器空值导致的白屏。
- 完善原生服务状态、更新检查和端口设置；端口修改即时生效，冲突时保留现有设置。
- 从旧名称升级时保留账号、历史、证书及开机启动选择，并兼容旧客户端的更新校验地址。

## 安装

使用 [README 安装命令](https://github.com/cloudshadow/mac-monitor/blob/v0.1.8/README.md#install-the-prerelease)，或下载对应架构的安装包、`install.sh` 和校验文件。应用入口为 `/Applications/Mac Monitor.app`。

附件提供 Apple Silicon（arm64）与 Intel（x86_64）安装包、SHA-256 校验清单及上方截图。应用采用 ad-hoc 签名，安装需要 macOS 管理员授权；本次沿用项目的预发布方式，硬件兼容和长期性能验收仍以项目发行检查表为准。
