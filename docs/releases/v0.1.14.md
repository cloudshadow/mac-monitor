# Mac Monitor v0.1.14

This release adds saved-data size reporting and disk-space cleanup, and makes history summaries and controls easier to read on desktop and mobile.

## Changes

- Show total saved-data size and history database size in the control window.
- Clear monitoring history after confirmation and compact the database to reclaim disk space. Cleanup runs in the background and preserves the account, settings, TLS certificates, and recording preference.
- Align the history range, metric, and retry controls. Keep long metric names within the mobile Safari viewport.
- Replace application summary lines with a table showing each five-minute window, average CPU, peak memory, cumulative disk reads and writes, and the top-ten categories that retained each application.
- Fix summary labels showing repeated “Loading…” when opening History directly from Overview.
- End loading indicators after failed queries, report application-summary failures, and show recording errors instead of incorrectly displaying “Recording”.
- Include application-summary windows that overlap the requested range and index application history by time.
- Remove migration of legacy installation directories and application names. Normal upgrades and reinstallation with saved data remain supported.

## Installation

Use **Check for updates → Install update** in v0.1.13, or follow the [installation commands in the README](https://github.com/cloudshadow/mac-monitor/blob/v0.1.14/README.md#install).

Packages are provided for Apple Silicon (`arm64`) and Intel (`x86_64`) on macOS 14 or later. Apple Silicon is the target platform; the Intel package is available for development testing. The app uses ad-hoc signing and may require macOS first-launch approval. Installation requires administrator authorization.

## Validation

- 51 Swift tests, including day/week queries, application-summary overlap and pagination, disk-space reclamation, recording preference preservation, and saved-data size calculations that exclude symbolic links.
- Production web build, TypeScript and localization checks, eight Chrome browser tests, and three mobile WebKit tests.
- Installer reinstallation, service preferences, unsafe-path rejection, GUI authorization handoff, argument quoting, canceled authorization, and checksum checks.
- HTTP, port configuration, and LAN HTTPS smoke tests.
- Both package architectures, signatures, bundled installers, versions, and SHA-256 checksums verified.

## Known limitations

Day and week history queries succeeded through the browser against a copy of existing history data. The previously reported query failure was not reproduced locally, so its specific cause remains unconfirmed. Privileged installation and Intel runtime were not exercised on this machine.
