# Mac Monitor v0.1.9

This release fixes repeated loading labels on mobile and makes errors visible without scrolling to the bottom of the page.

## Changes

- Wait for each page's translation resources before rendering its contents, so slow connections show one loading message instead of a screen full of loading labels.
- Display errors from sign-in, the dashboard, applications, history, language changes, and sign-out in a shared toast at the top of the screen.
- Merge duplicate errors while the toast is visible. Toasts disappear after six seconds and can also be closed manually.
- Keep error notifications within narrow mobile viewports, including when the page is scrolled.

## Installation

Use the [installation commands in the README](https://github.com/cloudshadow/mac-monitor/blob/v0.1.9/README.md#install), or download the package for your architecture, `install.sh`, and its checksum files below.

Packages are provided for Apple Silicon (`arm64`) and Intel (`x86_64`) on macOS 14 or later. Apple Silicon is the target platform; the Intel package is available for development testing. Updates preserve your account, history, certificates, and service-start preferences.

The app uses ad-hoc signing and may require macOS first-launch approval. Installation requires administrator authorization. Sensor availability depends on the Mac model and drive connection; hardware and long-running performance acceptance are tracked in the [release checklist](https://github.com/cloudshadow/mac-monitor/blob/v0.1.9/docs/release-checklist.md).
