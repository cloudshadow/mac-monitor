# 手机配对与验收

1. 在 Mac 控制端创建唯一账户，选择可用的物理网络接口并开启 LAN；只绑定该接口地址。
2. 生成配对码。将控制端显示的 CA 证书传到目标手机，核对它来自这台 Mac。服务私钥无需且不应复制。
3. iOS 在系统设置安装该证书描述文件，再在证书信任设置中为该本地 CA 开启信任；组织管理策略可能禁止此操作。Android 按系统证书设置导入用户 CA。不同系统版本需按实际界面确认。
4. 扫描五分钟有效的配对码。浏览器先完成 TLS 校验，再使用 fragment 里的票据兑换设备资格；地址 fragment 会清除。配对成功后仍需输入账户密码。
5. 手机浏览器使用 Secure/HttpOnly/SameSite=Strict 的设备及会话 cookie。退出只撤销本次账户会话；本机设备列表可撤销设备资格和对应活动流。
6. 网络地址改变后控制端更新地址，服务证书更新 IP SAN，使用同一个本地 CA；旧 IP 不继续监听。Cookie 按地址隔离，设备需在新地址重新配对并登录。

自动测试已验证本地 CA 链与 IP SAN、未配对拒绝、配对不自动登录、联合认证及设备撤销。未把这些结果当作 iOS Safari/Android 真机通过。真机需验证证书导入、360px 页面、睡眠恢复、网络切换、3 个活动流及撤销最迟 5 秒生效。不要跳过 TLS 错误继续操作。

iOS 手动证书信任步骤以 [Apple 官方说明](https://support.apple.com/en-au/102390) 为依据；手机端验收仍待用户执行。
