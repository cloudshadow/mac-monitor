# 局域网访问与验收

1. 在 Mac 本机网页首次访问时创建账户。服务默认在 en0 的有效 IPv4 地址开启 HTTPS；控制窗口会显示当前局域网地址。无需开启局域网或配对设备。en0 未连接时本机监控不受影响，服务每 30 秒重试网络状态；不会改用 en1 等接口。
2. 将控制窗口显示路径下的 `ca.pem` 公共 CA 证书传到其他设备，确认它来自这台 Mac。仅复制 `ca.pem`，不要复制同目录的私钥文件。
3. 设备信任本地 CA 后，打开控制窗口显示的 HTTPS 地址，使用本机创建的相同账号和密码登录。首次创建账户及损坏账户恢复仍需回到 Mac。
4. iOS 安装证书后，还需要在证书信任设置中启用该本地 CA 的信任；Android 按系统证书设置导入用户 CA。设备管理策略可能限制证书安装。不同系统界面仍需真机验证。
5. LAN 会话使用 Secure/HttpOnly/SameSite=Strict cookie，独立于本机 HTTP 会话。没有设备资格或设备撤销列表；退出撤销当前会话，Mac 重置密码会撤销所有既有会话和活动流。
6. en0 地址改变后只监听新地址，证书更新 IP SAN 并继续使用原本的 CA。新地址下重新登录即可，不需要重新配对。局域网地址可能使用空闲端口，以控制窗口显示的完整地址为准。

自动测试验证默认 en0 HTTPS、CA 链/IP SAN、远程创建账户被拒绝、无配对密码登录、错误密码拒绝、本机/LAN 会话隔离、3 个活动流上限、重置密码关闭旧流及退出会话。iOS/Android 证书信任、网络切换及 Apple Silicon 无桌面运行仍需目标硬件验收。
